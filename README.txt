USA Technical Trip 2026 — PWA

IMPORTANTE:
Um PWA não pode ser instalado diretamente a partir do app Arquivos (file://).
Ele precisa ser servido uma vez por HTTPS.

Maneiras simples de testar:
1. Publique os arquivos desta pasta em GitHub Pages, Netlify ou Cloudflare Pages.
2. Abra o endereço no Safari do iPhone.
3. Toque em Compartilhar > Adicionar à Tela de Início.
4. Abra o ícone criado.
5. Depois da primeira abertura, o conteúdo funciona offline.

Arquivos:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
